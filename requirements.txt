# 임베딩 모델 패키지 실행에 필요한 라이브러리 (버전 고정)
# 현재 개발 .venv 기준. 오프라인 서버에도 동일 버전으로 설치할 것.
#
# ⚠️ torch 설치 순서 (GPU 서버는 반드시 이 순서로) -----------------------------
# 이 파일을 그냥 `pip install -r requirements.txt` 하면 torch가 PyPI 기본
# 인덱스에서 잡히는데, PyPI에는 CPU 전용 빌드만 올라가 있다(CUDA 빌드는
# 용량 문제로 PyTorch 자체 저장소에만 있음). 그래서 GPU 서버에서도 이 순서를
# 안 지키면 조용히 CPU 빌드가 깔리고, GPU가 있어도 안 쓰인다.
#
#   1) torch만 먼저, CUDA 인덱스에서 설치 (버전은 실제 존재하는 채널로 --
#      cu126은 2025년 하반기 기준 확인값. torch 버전을 바꾸면 다시 확인할 것:
#      `pip install torch==<버전>.존재안함 --index-url .../whl/cuXXX` 실행 시
#      에러 메시지에 그 채널의 실제 버전 목록이 나온다.)
#        pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cu126
#   2) 나머지는 평소처럼 (이미 깔린 torch는 안 건드림)
#        pip install -r requirements.txt
#
# CPU만 있는 서버라면 1)을 건너뛰고 그냥 아래 목록대로 설치하면 된다.
#
# 오프라인 설치 시(인터넷 되는 PC에서 wheel 수집 후 서버로 반입):
#   1) torch(GPU 서버용) : pip download torch==2.13.0 --index-url https://download.pytorch.org/whl/cu126 -d offline_wheels
#      torch(CPU 서버용) : 별도 다운로드 불필요, 아래 3)에서 함께 받아짐
#   2) 나머지 라이브러리 : pip download -r requirements.txt -d offline_wheels
#   3) 서버에서 인터넷 없이 설치:
#        pip install --no-index --find-links=./offline_wheels -r requirements.txt
